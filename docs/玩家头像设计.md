# 玩家头像设计

个人信息页的圆角正方形头像框本身是上传按钮，鼠标悬停显示可点击光标，框内底部三分之一覆盖浅色“点击更换头像”提示。点击后选择 PNG、JPEG 或 WebP 图片。浏览器将图片居中裁成 128×128 的正方形并转为 JPEG；服务端校验格式和大小后存入账号数据库。头像 URL 按版本缓存，上传后通知在线客户端刷新。

玩家列表、好友列表、私聊气泡和房间阵营位置共用圆角正方形头像框。阵营位置的头像放在昵称左边。未上传头像或图片加载失败时，框内显示昵称的首个字。

上传接口为 `POST /api/auth/avatar`，图片读取接口为 `GET /api/avatar/:accountId?v=版本`。上传需要登录；服务端限制图片不超过 100 KB。账号表保留头像数据、MIME 类型与版本号，旧账号自动补列。
