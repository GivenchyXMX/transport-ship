# 架构拆分黑盒测试清单

本清单用于验收当前运输船架构拆分。请用平时的启动方式打开 `/transport-ship-mp.html`；不需要创建新地图或新房间类型。前半段可单人完成，联机段使用**现有房间流程**和两个登录账号。遇到异常，记录步骤、位置、预期与实际差异，最好附截图或控制台报错。

## 单人：场景和操作

- [ ] **加载与菜单**：页面加载至主菜单；运输船、海面、天空、灯光、贴图和菜单镜头正常，没有黑屏、白块或持续加载。菜单、计分板和雷达标签显示“运输船”。
- [ ] **开局与出生**：点击“开始游戏”；两队出生点在船内、方向正确，计时、比分、血量、弹药和雷达出现。
- [ ] **移动与碰撞**：在出生区、中央集装箱和两侧通道移动、跳跃、蹲下、攀上高处；不能穿墙、卡在箱体或走出船体。重点看侧路管道、窗口和箱体边角。
- [ ] **窗口与遮挡**：隔着实心箱体开火应被遮挡；在允许射击的窗口位置开火应符合改造前行为。注意人物是否能错误穿过窗口或墙体。
- [ ] **bot 与雷达**：两队 bot 从出生区出发，能走中路、侧路、绕箱和交战；狙击手仍会守点。雷达轮廓、自己的朝向、队友和敌人标记与现场位置一致。
- [ ] **武器与反馈**：主副武器、换弹、刀、手雷、切枪、命中反馈、击杀提示和音效可用；关注枪口、弹道和爆炸特效是否缺失。
- [ ] **死亡与循环**：击杀 bot、被击杀、复活；按 Esc 暂停并返回菜单，再开一局。第二局的画面、按键、bot、雷达和比分重新正常工作，菜单背景仍是运输船。
- [ ] **画质与窗口**：切换现有画质设置或调整浏览器窗口尺寸，再进入对局；画面比例、灯光、HUD 和雷达无明显异常。

## 双人：现有联机房间

- [ ] **入口与选图**：两名账号打开“联机对战”、登录；创建房间区域的地图、人数、目标分数、bot 数四个下拉框外观一致，展开和收起顺畅，鼠标点击、键盘方向键、Enter、Esc 均可操作。地图当前只有“运输船”；选择它建房，房间列表和等待页都显示运输船与对应海报。
- [ ] **入房与阵营**：一人按现有流程建房，另一人加入；双方选择不同阵营，房间人数、队伍和准备状态相互同步。
- [ ] **开局与出生**：满足原有开局条件后由房主开局；双方进入同一运输船，各自出生在正确阵营位置，不出现“地图版本不匹配”、黑屏或重复角色。
- [ ] **移动同步**：一人在出生区、中央箱体及侧路移动、跳跃和蹲下，另一人看到的位置与动作连续；不能在对方视角穿墙或凭空瞬移。
- [ ] **交火裁决**：近距离互射、隔着实心箱体互射、在窗口附近互射；命中、血量、死亡、击杀数和比分在两端一致。刀和手雷各验证一次。
- [ ] **复活与后加入**：一人死亡后复活，位置和状态两端一致；若现有房间支持进行中加入，再用现有流程加入一次，检查地图、队伍和当前比分同步。
- [ ] **退出与再来**：一人离开、另一人观察成员状态；回到菜单再进入联机，或按现有“再来一局”流程操作。确认没有残留幽灵角色、重复计分或失效按键。

如果暂时没有第二个账号，可先交付单人部分的结果；双人段标记为“未测”，不要按通过填写。
