# 房间邀请链接

房主在房间页点击“生成邀请链接”，服务端确认其房主身份和房间未满后签发随机令牌，默认 30 分钟有效。可用 `ROOM_INVITE_TTL_MINUTES` 配置为 1–1440 分钟。每次点击生成一条新链接，旧链接继续有效直到过期或房间关闭。

链接的令牌位于 URL fragment。落地页立即清除地址栏令牌，查询服务端房间信息后带着入房意图跳转联机页面。登录或注册完成、WebSocket 连上大厅后自动入房。登录页显示地图、房主昵称、当前人数、空位、击杀目标和单局时间限制；人数是打开链接时的快照，入房时以服务端实时人数为准。

服务端只保存令牌摘要，并在实际入房时检查令牌期限、房间实例、踢出名单、人数上限和对局状态。房间关闭或服务器重启后链接失效。满员时落地页提示无法进入；如果打开后才满员，入房请求返回“房间已满”，用户留在大厅。
