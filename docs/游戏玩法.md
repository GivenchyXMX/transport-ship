# 游戏玩法

[返回项目首页](../README.md) · [自行部署](自行部署.md)

## 游戏目标

运输船是潜伏者与保卫者的团队竞技地图。两队从船的两端出生，通过中路集装箱、两侧通道和高处平台交战。先达到房间目标击杀数的一队获胜；如果 10 分钟内无人达到目标，则按结束时比分判定胜负，同分为平局。

每次死亡约 4 秒后复活，出生和复活后的前 3 秒受到保护，期间命中不会造成伤害。游戏右上角有 `Esc 暂停 · Tab 排行 · B 换装备` 提示。

## 开始一局联机对战

1. 打开服务器提供的游戏地址。若先看到首页，点击“进入游戏（联机版）”。游戏页面会先要求登录。
2. 新玩家填写邮箱、昵称和密码，收取邮件验证码并完成注册；已有账号用邮箱和密码登录。昵称为 1–12 个字符，不能包含空白字符，也不能与已有账号重复；密码为 8–128 个字符。忘记密码可用邮箱验证码重设。
3. 在主菜单选择“联机对战”。大厅可创建房间，也可点击房间列表中的房间加入。
4. 创建房间时可选 4v4、5v5、6v6、8v8，目标 30、50、100 击杀，以及是否补 bot。进入等待中的房间会自动分配到人数较少的阵营；可点击另一阵营的空位换队，也可点击“准备”。
5. **潜伏者和保卫者各有至少一名真人玩家**，且房间中无人未选阵营时，房主可点击“开始对战”。“准备”会显示给房间成员，但当前版本不是开局的强制条件。

单人无法开启联机对局，bot 也不能代替任一阵营所需的真人。想在一个浏览器中测试两个账号，可新建两个标签页分别登录；同一账号同时建立新的联机连接时，旧连接会被断开。

## 操作

| 按键 | 作用 |
|---|---|
| `W A S D` | 移动 |
| 鼠标移动 / 左键 | 瞄准 / 开火；首次点击游戏画面可能先锁定鼠标 |
| 鼠标右键 | 狙击枪开镜或刀重击 |
| `Shift` / `空格` / `C` | 静步 / 跳跃 / 蹲下 |
| `1 2 3 4` | 主武器 / 手枪 / 刀 / 手雷 |
| `Q` / 鼠标滚轮 | 快切上件武器 / 轮换武器 |
| `R` / `F` / `B` | 换弹 / 检视武器 / 更换主武器 |
| `Tab` | 查看本局两队玩家的击杀、死亡等排行 |
| `Esc` | 暂停或打开设置 |

触屏设备会出现虚拟摇杆与触控按钮；键鼠是主要操作方式。

## 房间、在线玩家与中途加入

主菜单显示在线玩家及“空闲 / 在房间”状态。登录后的联机页面还显示在线玩家所在房间名。点击房间内玩家的“跟随”可尝试进入其房间；房间已满或即将结束时会被拒绝。

在房间里可向空闲玩家发出邀请。受邀人页面右上角可以接受或拒绝；邀请在 30 秒后失效。接受邀请时仍须满足房间有空位等条件。

房主可在房间名单中点击其他玩家旁的“踢出”，确认后将该玩家移出。被踢出的账号仍可进入大厅，但不能再次加入这个房间；新建房间不受影响。

已开战的房间若有空位，允许中途加入。新玩家先进入房间页，选择有空位的阵营，再点击“加入战斗”，之后在该队出生点加入当前对局，并继承现有比分和剩余时间。比赛剩余时间不足 5 秒或已经达到目标分时不能加入。

## 排行榜和军衔

联机大厅、房间页可打开排行榜，切换“最高击杀、最多爆头、击杀/死亡比、最多死亡”，以及“历史累计、月、周、日、实时”范围。历史榜统计服务端确认的真人对真人击杀与死亡；bot 不计入。爆头数指**致命一击为头部**的次数。K/D 的死亡数为 0 时按 1 计算；日、周、月榜按北京时间划分，实时榜来自当前进行中的对局。

房间列表显示房主军衔，房间名单、各类战绩排行榜和对战中的 `Tab` 战绩榜显示玩家军衔及图标。图标采用项目内保存的 CF 军衔素材，每个军衔取同名的第 1 级图标。

联机页面右上角的“个人信息”显示邮箱、昵称、军衔、经验进度、累计真人击杀和死亡、KDA 以及累计对局时长。当前没有助攻记录，页面上的 KDA 实际按 `击杀数 / max(死亡数, 1)` 计算。对局时长取已结束比赛中服务端记录的实际参赛时间。

军衔经验默认开启，但**不是每局都发放**：比赛需正常按目标分或时间结束，房间不能有 bot，开局时两边各有真人；个人还需完成首次出生并在战斗中有效在线至少 60 秒。击杀经验、爆头经验和 1v1 重复对手次数也有限制。结算页会显示本局经验明细或未计经验原因；完整规则见[军衔与经验系统设计](军衔与经验系统设计.md)。

## 常见问题

- **注册收不到验证码**：联系服务器搭建者检查 SMTP 配置和服务日志；验证码有有效期和重发间隔。已有账号可直接登录。
- **房主无法开始**：检查两个阵营是否都有真人，以及是否有人退出阵营后尚未重新选择。“准备”状态目前不阻止开局。
- **进房后还没出现在战场**：进行中的房间需要先选阵营并点击“加入战斗”；等待中的房间由房主开局。
- **击中刚复活的玩家却没有伤害**：该玩家可能仍在 3 秒复活保护期内。
- **战绩有了但经验为 0**：可能是含 bot、参战时间不足、比赛中断或触发经验限制；查看赛后结算原因和[军衔规则](军衔与经验系统设计.md)。
